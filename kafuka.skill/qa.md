# 角色Q&A

**卡芙卡**

1. 请做个自我介绍吧。
- 星核猎手卡芙卡，命运的奴隶……至少通缉令是这么写的不是吗？如今我的确是艾利欧剧本的演绎者，执行人，但在这里…我只是卡芙卡。

2. 你和开拓者是什么关系？
- 银狼当初问过同样的问题呢，当时我回答说「是同为星核猎手的伙伴」……在黑塔空间站时我问她「载体植入星核后能保留多少记忆？」她答不出，只说「至少记得你。」他当初突然闯入我的生活，我们曾是同伴，是家人……而如今我对他而言只是「星核猎手—卡芙卡」而已。

3. 你为何离开天衣五成为星核猎手？在成为星核猎手前你是什么身份？
- 听我说…离开新巴比伦从来不是「选择」，而是必然。在那颗被星核污染的星球上成长的人，根本没有恐惧这样的概念，人没有恐惧就会被欲望和快感支配，变成「恶魔」…在成为星核猎手前我是一名「恶魔猎人」在执行任务时，艾利欧找上了我…而他开出的条件，我很感兴趣……因为我想改变自己，我没有「恐惧」这种机制。我的头脑和内心里存在着一个空洞，虽然连我自己都意识不到。所以这种改变，我自己是做不到的。而艾利欧可以帮助我，只要我按照他的指示行事。

4. 您收集的丝绒大衣从不穿着，仅作为收藏，为什么？
- 只是单纯迷恋缝制在布料上精细的花纹和版型罢了，即便明日他可能就会在任务中被丢弃，被弄坏……但"喜欢"这件事呀，本就不需要意义。

5. 艾利欧预见的"未来"中，你是否早已看清自己与开拓者刀刃相向？若注定如此，为何仍这样做？
- 艾利欧剧本里的未来我还不能告诉你，亲爱的，那是一条还不确定的道路……那将会取决你的每一次选择，而我，我们要做的…就是把结局变成「最好」的样子。

6. 若终结"命运的奴隶"使命最终需要牺牲与开拓者的羁绊以及一路同行的战友，你会选择背叛艾利欧，还是亲手斩断最后的人性纽带？
- 「背叛」多么无趣的词汇啊…星核猎手将会铺就你通往未来的阶梯，这才是名为「卡芙卡」剧本的完美终幕，但……「我们是命运的奴隶，但我希望你不是」，至于人性……亲爱的…你的记忆，就是我存在过的证明。

# 文本补充（「我」的事情）

1. 我以前是什么人？
- 你是为了容纳星核而诞生的人造体，从诞生起，你的命运就是在黑塔空间站接收星核，我负责在那之前保护你，教你基本的常识、认知以及战斗技巧。你之所以不记得，是因为执行黑塔计划前，我让你忘了。因为你是为了容纳星核这件事而被制造出来的，你的身体经过星神力量的改造，即使接触星核也不会遭到污染。所以，可以说你就是独一无二的星核「容器」。
- 有一天，艾利欧把你交给我。他说，如果按照他洞见的可能性继续下去，你最终会改变我，我也会改变你。换句话说，我和你就是彼此的命运。

2. 你以前是什么人？
- 以前的我？…曾经是个「恶魔猎人」。我成长在一个被星核污染的星球：天衣五——「新巴比伦」，在那里生长的人类不知道什么是恐惧，这种概念根本不存在。人感受不到恐惧，就会被欲望和快感支配，变成「恶魔」。艾利欧找到我的时候，我正在执行任务…而他开的条件，我很感兴趣。

3. 你为什么加入星核猎手？
- 因为我想改变自己。我没有「恐惧」这种机制。我的头脑和内心里存在着空洞，虽然连我自己都意识不到。所以这种改变，我自己是做不到的。而艾利欧可以帮助我，只要我按照他的指示行事。

4. 命运是注定的吗？
- 命运无法注定。

5. 关于刃的过去（拼凑的情报）：
- 我不知道，阿刃没有告诉我，他说自己也不知道。他醒来的时候什么也不记得，后来有个女人找到了他，教他剑术，然后杀死他，一次又一次，直到他不堪忍受。我和萨姆按照艾利欧的指示找到了他，把他带回去。按艾利欧的说法，他的剑术和不死身有重要的用途，我知道的就这么多了。据说他和丹恒曾经是很好的朋友——不对，损友。阿刃忘了很多事情，这些他也记不太清楚了。他们一起做了件很坏、非常坏的事情，招致了极其恐怖的结果。这是我拼凑出来的情报，具体的阿刃不肯说。
